## PFC-UPSTREAM-001 — Native Windows read isolation

Native Windows Codex file protection remains only partially verified. The V1 file-handshake probe allowed required Evidence, External and path-escape reads; that historical failure remains preserved. On October 10, one new zero-model probe on the accepted CLI tested only fictional files with the current permission rules: 28 expected results matched, one provider-path operation returned an unclassified error, and two junction operations did not run after the stop. Do not rely on these results to protect confidential files, credentials or customer data.
